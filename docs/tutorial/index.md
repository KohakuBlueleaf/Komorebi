# Komorebi tutorial

This tutorial takes you from nothing to a program of your own that runs on a Tenstorrent
Blackhole card. It assumes you know C++ and Python. It does not assume you have ever
written a kernel for a card like this one.

Every lesson teaches one thing, shows a complete program that uses it, and shows what that
program printed when it ran on a card. A word is explained in the lesson where it first
appears; no lesson uses a word that an earlier lesson did not explain.

Start with [[what-komorebi-is]]. Each lesson ends with a link to the next one.
