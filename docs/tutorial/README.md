# Tutorial sources

These files are the sources of the tutorial site, a step-by-step course in the Komorebi
programming model; they are written for the site, not for reading here. Build and read
the site locally with `mkdocs serve` (or `mkdocs build --strict` for a static copy in
`site/`) after `uv pip install -e ".[dev]"`; the runnable example of each page is in
the folder of the same number under `tutorial/` at the repository root.
